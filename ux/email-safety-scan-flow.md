AI Email Safety Scan — UX Flow

Status: Draft
Related Concept: AI Email Safety Scan  
Created: August 2026
1. Entry Point: User Opens an Email

The user opens an email in their inbox.
This is the moment where risk begins — especially for mobile‑only users.

Triggers:

    User taps an email

    User scrolls through the message

    User activates an AI action (Summarize, Explain, Translate)

2. AI Safety Scan Automatically Activates

The system silently runs a background scan before performing any AI action.

Scan checks for:

    vague or manipulative language

    urgency or fear‑based threats

    mismatched sender domains

    unsafe links or redirects

    known phishing templates

    abnormal patterns compared to user behavior

    generic greetings

    suspicious attachments

This step is invisible to the user — no friction, no overwhelm.
3. Safety Scan Result: Safe or Suspicious
A. Safe Email Path

If the email appears safe:

    AI proceeds normally

    User sees the requested AI action (summary, explanation, etc.)

    A small reassurance indicator appears:
    “AI Safety Scan: No issues detected.”

This builds trust without adding noise.
B. Suspicious Email Path

If the email appears unsafe:

    AI pauses the requested action

    A visible warning appears at the top of the email

    The warning uses calm, non‑alarming language:

    “This email appears unsafe. Be cautious before clicking links or responding.”

User options:

    View details

    Return to inbox

    Delete email

    Report phishing

This is trauma‑informed: clear, calm, and empowering.
4. Optional: View Safety Details

If the user taps View details, they see a simple breakdown:

    Suspicious sender domain

    Urgent or threatening language

    Unsafe links

    Known phishing pattern match

    Generic greeting

    Attachment risk

This page is intentionally short — no technical jargon.
5. User Action & System Response
If user deletes the email:

    Email moves to Trash

    AI logs the pattern to improve future detection

    User sees:
    “Email deleted. AI Safety Scan updated.”

If user reports phishing:

    Email is sent to provider’s abuse team

    AI strengthens pattern recognition

    User sees:
    “Thank you. This helps improve safety for everyone.”

If user returns to inbox:

    No further action

    Email remains flagged

    AI continues monitoring similar patterns

6. End of Flow

The user returns to normal inbox activity.
The system continues learning silently in the background.
